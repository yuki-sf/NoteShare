# ✨ NoteShare 🔗

Welcome to **NoteShare** — the easiest way to securely share **notes**, **files**, and **links** with your own personalized style. Whether it’s a quick thought, a PDF, or a super-secret recipe, NoteShare makes sharing simple, beautiful, and fast! 🚀📄💜

## 🎯 What Can NoteShare Do?

| Feature            | Description |
|--------------------|-------------|
| 📝 Share Notes      | Create and send clean text notes with a custom link |
| 📁 Upload Files     | Upload any file type and get an instant download link |
| 🔗 Custom Links     | Choose your own short and catchy share URLs |
| ⏳ Expiration Rules | Set how long your content lives or how many views it gets |
| 📊 View Analytics   | See how many people viewed your note or file |
| 🔐 Secure & Private | Backed by **Supabase**, your content stays safe and yours |

## 🛠️ Getting Started Locally

```
# Clone the repository
git clone https://github.com/your-username/NoteShare.git
cd NoteShare

# Install dependencies
npm install
```


### Add your Supabase credentials in a `.env` file
```
VITE_Supabase_Url=your_supabase_url
VITE_Supabase_Key=your_supabase_anon_key
```
```
# Run the app locally
npm run dev
```
